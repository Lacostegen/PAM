# Модели

В проекте используются разные типы моделей, и их важно не смешивать.

## GGUF-модель чата

GGUF-модель используется только во вкладке общения с моделью.

Ожидаемое расположение:

```text
Translator/
```

Пример:

```text
Translator/Qwen3.5-9B-Uncensored-HauhauCS-Aggressive-Q4_K_M.gguf
```

Для запуска локальной GGUF-модели также нужна папка:

```text
NativeLlama/
```

В ней должны лежать:

```text
llama-server.exe
*.dll
```

## Word2Vec и FastText

Word2Vec/FastText - отдельная структура, она не относится к GGUF-чату.

Ожидаемое расположение:

```text
Models/
```

Для этих моделей используются `.bin`-файлы.

## Что нельзя коммитить

Не добавляйте в Git:

- `.gguf`;
- большие `.bin`-модели;
- `NativeLlama/`;
- локальные настройки модели из `Config/`.

Эти файлы нужно передавать отдельно.
